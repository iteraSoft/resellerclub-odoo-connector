ResellerClub Integration for Odoo

Odoo 19.0 LGPL-3 HTTP API

Complete integration with ResellerClub HTTP API for managing domains, hosting, SSL certificates, and more directly from Odoo.

Key Features

🌐 Domain Management

  • Register new domains
  • Transfer from other registrars
  • Renew domains
  • DNS management
  • WHOIS privacy protection

🖥️ Hosting Services

  • Single/Multi domain hosting
  • Reseller hosting
  • Email hosting
  • VPS & Dedicated servers

🔒 SSL Certificates

  • DV, OV, EV certificates
  • Wildcard & Multi-domain
  • CSR generation
  • Automatic enrollment

👥 Customer Management

  • Sync with Odoo contacts
  • Auto-create in ResellerClub
  • Contact management
  • Customer portal

📊 Sales Integration

  • Product synchronization
  • Automatic provisioning
  • Order tracking
  • Pricing with margins

🔔 Notifications

  • Expiry reminders
  • Customer emails
  • Activity scheduling
  • Renewal alerts

Configuration

Getting Started:
  1. Install the module from Apps
  2. Go to Settings > ResellerClub
  3. Enter your Reseller ID and API Key
  4. Test the connection
  5. Sync products from ResellerClub

Customer Portal

Your customers can manage their services through the Odoo portal:

  • View all domains, hosting, and SSL certificates
  • Check expiration dates and status
  • See service details and configurations

API Endpoints

The module provides the following API endpoints:

Endpoint Description
/resellerclub/domain/check Check domain availability
/resellerclub/domain/suggest Get domain name suggestions
/resellerclub/webhook Webhook handler for status updates

Technical Information

  • Dependencies: sale_management, account, contacts, product, mail, portal, website_sale
  • Python Dependencies: requests
  • API: ResellerClub HTTP API
  • Test Mode: Supports ResellerClub sandbox environment
